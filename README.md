# Industrial Equipment Monitor

A Python-based industrial equipment monitoring application designed to simulate machine operations, track equipment status, and demonstrate backend software engineering concepts.

## Project Goals

- Practice Python programming and object-oriented design.
- Simulate industrial equipment and machine operating states.
- Monitor machine status and operating data.
- Build a backend API for equipment information.
- Develop a web dashboard for monitoring equipment.

## Planned Technology Stack

- **Language:** Python
- **Backend:** FastAPI (planned)
- **Database:** SQLite (planned)
- **Frontend:** HTML, CSS, JavaScript (planned)
- **Version Control:** Git and GitHub

## Development Roadmap

- ✅ Milestone 1: Python machine dictionaries and terminal application
- ✅ Milestone 2: Machine monitoring logic
- ✅ Milestone 3: Data storage and history
- ✅ Milestone 4: REST API
- [ ] Milestone 5: Web dashboard
- [ ] Milestone 6: Testing and deployment
